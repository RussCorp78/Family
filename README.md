POLAROID PHOTO GALLERY

Files
- index.html  : page structure
- style.css   : all styling and responsive layout
- script.js   : temporary photos, search and navigation

To test
1. Extract the ZIP file.
2. Open index.html in a browser.

To use your own test photos
1. Create an images folder beside index.html.
2. Put your photographs into that folder.
3. In script.js, change each image value, for example:
   image: "images/my-photo.jpg"

The current sample images are loaded from Unsplash, so an internet connection is required until you replace them.

GitHub Pages
Upload all four files to a GitHub repository. Keep index.html, style.css and script.js in the same folder, then enable GitHub Pages for the repository.
